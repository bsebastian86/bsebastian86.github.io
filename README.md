# Ben Sebastian Portfolio

A modern recreation of the original [bsebastian86.github.io](https://bsebastian86.github.io/) portfolio.

Same sections and copy — Home, About, Work, Process, Contact — rebuilt as a Vite + React + TypeScript app with semantic markup, CSS custom properties, and a data-driven Work gallery so projects can be updated later.

```bash
npm install
npm run dev
```
